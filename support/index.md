# よくある質問・お問い合わせ

## よくある質問

### 歩数が ふえません

歩数を読む許可が オフに なっているかもしれません。

- iPhone：「設定」→「プライバシーとセキュリティ」→「モーションとフィットネス」で、「フィットネス・トラッキング」と SomeBuddy を オンにしてください
- Android：「設定」→「アプリ」→「SomeBuddy」→「権限」で、「身体活動」を 許可してください

歩数の計測は、スマホに 歩数を数える しくみ（センサー）が あるときだけ できます。

### 位置情報を 許可しないと、遊べませんか

遊べます。iPhone では、さんぽ中に 画面を消しても 歩数を数えつづけるためだけに 位置情報を使います。どこを歩いたかは 記録も 送信も しません。
許可しない場合は、画面を消しているあいだ、ロック画面の歩数表示が アプリを開くまで 更新されなくなります。
iPhone では、アプリの「せってい」→「位置情報について」でも、いつでも 説明を見られます。

Android 版は、位置情報の許可を使いません。

### さんぽの お知らせが 届きません

アプリの「せってい」→「お知らせ」で、お知らせが オンに なっているか、時刻が あっているかを 見てください。
スマホの「設定」で、SomeBuddy の 通知が 許可されているかも 見てください。

### 歩かない日が つづくと、どうなりますか

なにも へりません。犬が 元気を なくすことも ありません。また 歩きたくなったときに、つづきから どうぞ。

### 機種変更のとき、データは 引きつげますか

データは スマホの中だけに 保存しています。アカウントは ありません。

- iPhone から iPhone、Android から Android へは、スマホの バックアップ（iPhone の iCloud バックアップ、Android の Google のバックアップ）から 新しいスマホに 移すと、遊んだ記録も 引きつげます
- iPhone と Android の あいだでは、いまは 引きつげません

アプリを 削除すると、スマホの中の データも 消えます。

### iPad で 遊べますか

いまは iPhone と Android の スマホだけです。

## お問い合わせ

不具合や ご感想は、こちらに お送りください。

aki11ermom@gmail.com

不具合のときは、次も 書いてもらえると 助かります。

- スマホの 機種（例：iPhone 16、Pixel 8）と、OS の バージョン
- アプリの バージョン（わかれば。iPhone は「設定」→「一般」→「iPhone ストレージ」→「SomeBuddy」、Android は「設定」→「アプリ」→「SomeBuddy」で 見られます）
- どの画面で、なにを したときに 起きたか（スクリーンショットが あると とても助かります）

アプリの「せってい」→「感想を おくる」からも、かんたんな アンケートで 送れます。

ひとりで 作っているので、お返事に 少し 時間が かかることが あります。
