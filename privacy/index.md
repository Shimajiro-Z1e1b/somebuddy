# SomeBuddy プライバシーポリシー

丹青二才（以下「わたし」）は、アプリ「SomeBuddy」（以下「本アプリ」。iPhone 版と Android 版）での情報の あつかいを、次のように定めます。

## 1. 本アプリが使う情報

本アプリが使う情報は、すべて お使いの端末の中で あつかいます。わたしや ほかの会社に送ることは ありません（「2. 外部に送られる情報」の感想フォームを のぞく）。

| 情報 | 使いみち | 保存する場所 |
|---|---|---|
| 歩数 | さんぽの歩数を数え、毎日の目標に届いたかを判定するため。iPhone は「モーションとフィットネス」、Android は「身体活動」の許可を使います | お使いの端末の中だけ |
| 位置情報（iPhone のみ） | さんぽ中に画面を消しても、歩数を数えつづけるため（ロック画面の歩数表示を更新しつづけるため）。使うのは さんぽ中だけで、さんぽを終えると止めます。位置そのものは使わず、どこを歩いたかは記録も送信もしません。許可しなくても さんぽは できます（画面を消しているあいだ、ロック画面の歩数表示が アプリを開くまで更新されなくなります） | 保存しません |
| 通知 | 毎日の さんぽの お知らせを、端末の中で予約するため。Android では、さんぽ中の歩数を通知に出します | お使いの端末の中だけ |
| 写真への追加（iPhone のみ） | 届いた手紙と写真を画像にして「写真」に保存するため。ご自身で共有シートの「画像を保存」を選んだときだけ使います。写真ライブラリの中身は読みません | お使いの端末の「写真」 |
| アプリの中で入力した名前など（犬の呼び名・ニックネーム）と、遊んだ記録 | アプリの中で表示するため | お使いの端末の中だけ |

Android 版は、位置情報の許可を使いません（さんぽ中は、歩数を数える通知を出して動きつづけます）。

本アプリには、アカウント登録・サインイン・広告・利用状況の分析ツール・クラッシュ報告の ツールは ありません。
本アプリ自身は、インターネットと通信しません（文字（フォント）も アプリの中に入っています）。わたしはサーバーを持っていません。

本アプリを削除すると、端末の中の情報も すべて消えます。
ただし、端末のバックアップ（iPhone の iCloud バックアップ、Android の Google のバックアップ）を お使いの場合は、遊んだ記録が その中にも入り、機種変更のときに引きつげます。バックアップの あつかいは、Apple または Google の しくみに したがいます。

手紙と写真を画像にして共有するとき（「がぞうで のこす」）は、OS の共有シートが開くだけで、本アプリから どこかへ送ることは ありません。送り先は ご自身で選びます。なお、「写真」に保存した画像や、ほかのアプリに渡した画像は、本アプリを削除しても消えません。

## 2. 外部に送られる情報

次の場合だけ、外部のサービスに情報が送られます。

- **感想フォーム（Google フォーム）**：せっていの「感想を おくる」を押すと、ブラウザで Google フォームが開きます。フォームには、アプリのバージョン・端末の種類（iPhone / Android）・集めた かけらの数・いっしょにいた日数・目標の歩数が 自動で入ります。名前などの個人を特定する情報は 自動では入りません。フォームに 名前を書く欄は ありません。送信するかどうかは、ご自身で決められます。送信された回答は、わたしの Google アカウントで管理し、本アプリの改善だけに使います。

Google での情報の あつかいは、Google のプライバシーポリシーを ご確認ください。

- Google：https://policies.google.com/privacy

## 3. 第三者への提供

法令にもとづく場合を のぞき、感想フォームで いただいた情報を 第三者に提供することは ありません。
